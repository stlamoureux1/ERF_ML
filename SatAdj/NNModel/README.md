# Model Information

## Training data 
    - data file: `samples100k.csv`
    - divided into test set (30%), validation and training sets
    - generated by `SatAdj/SatAdj_GenerateSamples.py -N 100000 -f samples100k.csv`

## Preprocessing:
    - Pressure scaled by `log_10`
    - qv and qc scaled by `log_10(1 + x)`
    - All variables rescaled by MinMaxScaler
        - scalers were fit on training data and applied to train / test / validation.
        - scalers exported to files `scaler_X.pkl` and `scaler_Y.pkl`

## Architecture
    - 2x256 hidden layers multi-layer perceptron
    - MSE loss for training, validation, and test
    - Adam optimizer

## Hyperparameters
    - trained on minibatches of size 64
    - 300 epochs
    - learning rate of 5e-5

## Results (scaled)
    - test MSE: 2.335e-06
    - exported model was additionally tested on `samples20k.csv` (generated separately):
        - total MSE:  ~1.0617e-05
        - MSE temperature: ~3.0735e-06
        - MSE qv: ~8.816e-06
        - MSE qc: ~1.996e-05
